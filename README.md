# ProLEEI-MT: páginas das declarações de participação

Este repositório público contém apenas as páginas do sistema de declarações do ProLEEI-MT (arquivos HTML, CSS e JavaScript):

- `index.html`: página em que a formadora pede as declarações das cursistas da turma dela;
- `verificar.html`: página que confere o código impresso na declaração (é a que o QR Code abre);
- `teste.html`: teste de conexão, usado por quem administra o sistema logo depois da instalação;
- `config.js`: o endereço do servidor do projeto (é o único arquivo que se edita);
- `logo.png`: o desenho dos pássaros do ProLEEI-MT, mostrado no topo das páginas (para trocá-lo, envie outro arquivo com o mesmo nome);
- `comum.js`, `pedido.js`, `verificar.js`, `teste.js`, `estilo.css` e `favicon.svg`: arquivos de apoio das páginas.

Aqui não há dados de cursistas, de formadoras nem senhas. Os dados ficam em uma planilha privada, e as páginas só conversam com o servidor do projeto.
Mantenha neste repositório somente estes arquivos. O passo a passo de instalação está no LEIA-ME do projeto (repositório privado da equipe), no Passo 7.
